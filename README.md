# typed-crt

A clean-room, from-scratch re-implementation of the idea behind **[steve245270533/typed-crt](https://github.com/steve245270533/typed-crt)** by [@steve245270533](https://github.com/steve245270533). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
